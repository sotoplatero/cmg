CMG - Convert My Graphics

A modern CLI tool for batch image conversion and optimization

🖼️

Multiple Formats

Convert between JPEG, PNG, WebP, GIF, TIFF, and BMP formats with ease.

⚡

Web Optimization

Optimize images for web with smart presets and quality settings.

📏

Smart Resizing

Resize images with web-friendly presets for desktop, tablet, and mobile.

Installation

Install globally (recommended):

npm install -g .

Or use without installation:

npx cmg

Interactive Options

Quality Presets

  • Maximum (100) - Lossless
  • High (90) - Photos
  • Medium (80) - Web optimal
  • Low (60) - Small file size
  • Custom quality...

Width Presets

  • Original size
  • Large (1920px) - Desktop
  • Medium (1280px) - Tablet
  • Small (768px) - Mobile
  • Thumbnail (320px)
  • Custom size...

Command Line Usage

cmg [options]

Options:
  -f, --format      output format (jpeg, png, webp)
  -q, --quality   output quality (1-100)
  -w, --width     resize image width
  -o, --output       output directory
  -r, --recursive         process subdirectories

Examples

# Basic usage with interactive prompts
cmg

# Convert to JPEG with 90% quality
cmg -f jpeg -q 90

# Convert and resize for desktop
cmg -w 1920

# Process all images in subdirectories
cmg -r
